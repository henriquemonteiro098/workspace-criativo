# Arquivo Vivo

Um workspace pessoal para transformar pesquisa, código e criação em próximos experimentos claros.

## Abrir a prova

Abra `index.html` no navegador. A página não exige instalação, build ou servidor: ela funciona como um índice filtrável das linhas de trabalho e aponta de volta para as fontes locais.

## O que foi consolidado

- Banco fictício: invariantes, transações atômicas, testes de fronteira e consistência entre camadas.
- Estudos financeiros: fontes públicas, perguntas de recuperação e limites explícitos do que uma fonte não cobre.
- Ponto Cego e Retratos Tech IA: estados por estágio, uma ideia por pasta e uma variável por iteração.
- Observações de processo: registro de fricções para melhorar o próximo ciclo.

## Arquivos principais

- `knowledge-map.md`: curadoria das fontes e regras transversais.
- `ARCHITECTURE.md`: decisão visual, comportamento e próximos incrementos.
- `index.html`, `styles.css`, `app.js`: primeira prova navegável.

Os arquivos SQL mantidos nesta pasta continuam disponíveis como material de estudo do banco. O projeto visual não os executa nem altera o banco de dados.
